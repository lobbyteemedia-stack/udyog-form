# উদ্যোগ আবেদন ফরম পূরণ সেবা

বাংলাদেশ ব্যাংকের "উদ্যোগ" কর্মসূচির আবেদন ফরম অনলাইনে পূরণের ওয়েবসাইট।

**কীভাবে কাজ করে**
1. ব্যবহারকারী বিনামূল্যে ৬ ধাপে পুরো ফরম পূরণ করেন (মোবাইলে সহজে)।
2. জমা দিলে অফিসিয়াল ফরমের ডিজাইনে **ওয়াটারমার্কসহ প্রিভিউ** দেখায় — ডাউনলোড করা যায় না।
3. ব্যবহারকারী বিকাশ/নগদে Send Money করে TrxID জমা দেন।
4. আপনি `/admin` প্যানেলে TrxID মিলিয়ে **অনুমোদন** দেন।
5. সাথে সাথে ব্যবহারকারীর পেজে **ওয়াটারমার্ক ছাড়া PDF ডাউনলোড** বাটন আসে (যতবার খুশি)।

## ফ্রিতে চালু করুন (Render + Neon, ডোমেইন লাগবে না)
১. **GitHub** (github.com) — অ্যাকাউন্ট খুলুন → New repository → নাম `udyog-form` → **Private** → Create।
   তারপর "uploading an existing file" চেপে এই zip-এর ভেতরের সব ফাইল ও ফোল্ডার টেনে দিন → Commit।
২. **Neon** (neon.com) — ফ্রি অ্যাকাউন্ট → New Project (Region: Singapore) → **Connection string** কপি করুন
   (দেখতে এমন: `postgresql://...neon.tech/neondb?sslmode=require`)।
৩. **Render** (render.com) — GitHub দিয়ে সাইন ইন → **New → Blueprint** → `udyog-form` রিপো বেছে নিন।
   চাইলে দুটো ঘর: `DATABASE_URL` = Neon-এর লিংক, `ADMIN_PASS` = আপনার শক্ত পাসওয়ার্ড → **Apply**।
৪. ৫–১০ মিনিট পর লিংক পাবেন: `https://udyog-form.onrender.com` (নাম আগে থেকে নেওয়া থাকলে একটু ভিন্ন হবে)।
   অ্যাডমিন: `https://udyog-form.onrender.com/admin` (ইউজার: admin)।

**ফ্রি প্ল্যানের সীমা:** ১৫ মিনিট কেউ না ঢুকলে সাইট ঘুমিয়ে যায়; পরের ভিজিটে চালু হতে প্রায় ১ মিনিট লাগে।
সব আবেদন Neon ডেটাবেসে থাকে, তাই রিস্টার্টে কিছু হারায় না। পরে মাসিক অল্প খরচে Render "Starter" নিলে ঘুমানো বন্ধ হবে।

## নিজের সার্ভারে চালাতে চাইলে
- একটি VPS / ক্লাউড সার্ভার (Ubuntu), **Node.js 18 বা নতুন**। শেয়ার্ড cPanel (শুধু PHP) হোস্টিংয়ে চলবে না।
- একটি ডোমেইন ও HTTPS (ব্যক্তিগত তথ্য ও NID থাকে, তাই HTTPS অবশ্যই লাগবে)।

## ইনস্টল
```bash
npm install                 # প্রথমবার Chrome-ও ডাউনলোড হবে (PDF তৈরির জন্য)
cp .env.example .env        # তারপর .env খুলে নম্বর ও পাসওয়ার্ড বসান
npm start
```
Ubuntu সার্ভারে Chrome চালাতে কিছু লাইব্রেরি লাগতে পারে:
```bash
sudo apt install -y libnss3 libatk1.0-0 libatk-bridge2.0-0 libcups2 libdrm2 libxkbcommon0 libxcomposite1 libxdamage1 libxrandr2 libgbm1 libasound2t64 libpango-1.0-0 libcairo2
```
সার্ভারে আগে থেকে Chrome থাকলে `.env`-এ `CHROME_PATH=/usr/bin/google-chrome` দিন।

সবসময় চালু রাখতে: `npm i -g pm2 && pm2 start server.js --name udyog && pm2 save`
Nginx দিয়ে ডোমেইনে যুক্ত করে Certbot দিয়ে HTTPS চালু করুন।

## .env সেটিং
| নাম | কাজ |
|---|---|
| `SITE_NAME` | সাইটের নাম |
| `PRICE` | ডাউনলোড ফি (ডিফল্ট ১০০) |
| `BKASH_NUMBER`, `NAGAD_NUMBER` | যে নম্বরে টাকা নেবেন (একটি ফাঁকা রাখলে সেটি দেখাবে না) |
| `ADMIN_USER`, `ADMIN_PASS` | `/admin` লগইন — শক্ত পাসওয়ার্ড দিন |
| `KEEP_DAYS` | এত দিন পর পুরনো আবেদন স্বয়ংক্রিয়ভাবে মুছে যাবে (ডিফল্ট ৬০) |

## অ্যাডমিন প্যানেল
`https://আপনার-ডোমেইন/admin` — "যাচাই বাকি" তালিকায় নতুন পেমেন্ট আসে। বিকাশ/নগদ অ্যাপে TrxID ও ৳১০০ মিলিয়ে **অনুমোদন** দিন, না মিললে কারণ লিখে **বাতিল** করুন (ব্যবহারকারী আবার TrxID দিতে পারবেন)। একই TrxID দুবার ব্যবহার করা যায় না।

## ফাইল
- `server.js` — সার্ভার, পেমেন্ট, অ্যাডমিন, ডাউনলোড
- `lib/layout.js` — কোন তথ্য অফিসিয়াল ফরমের কোন ঘরে বসবে
- `lib/render.js` — প্রিভিউ ও PDF তৈরি
- `assets/form.pdf` — অফিসিয়াল আবেদন ফরম (নতুন ফরম এলে এটা বদলাতে হবে এবং layout.js-এর ঘরের অবস্থান মিলিয়ে নিতে হবে)
- `data/apps/` — জমা হওয়া আবেদন (নিয়মিত ব্যাকআপ নিন; কাউকে শেয়ার করবেন না)

## গুরুত্বপূর্ণ
- সাইটে স্পষ্ট লেখা থাকে যে এটি সরকারি সাইট নয় এবং সরকারি আবেদন বিনামূল্যে — এই লেখা সরাবেন না। সরকারি সাইট বা বাংলাদেশ ব্যাংক হিসেবে প্রচার করলে আইনি ঝুঁকি আছে।
- আবেদনকারীর NID, ব্যাংক হিসাবসহ ব্যক্তিগত তথ্য সংরক্ষিত হয় — সার্ভার সুরক্ষিত রাখুন, HTTPS ছাড়া চালাবেন না।
- প্রিভিউ ছবি আকারে দেখানো হয় ও ওয়াটারমার্ক থাকে; তবে কেউ স্ক্রিনশট নিতেই পারে — এটা যেকোনো এমন সাইটের সীমাবদ্ধতা।
